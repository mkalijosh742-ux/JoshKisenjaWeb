HOW TO SET THIS UP
===================

1. Put these 4 files in the SAME folder:
   - index.html   (the site)
   - vid1.mp4      (your first video)
   - vid2.mp4      (your second video)
   - vid3.mp4      (your third video)

2. Double-click index.html to test it in your browser before sending it.

3. To edit the password, your birthday, your last name, her name, the
   game words, or the love-letter captions — open index.html in any
   text editor and look for the block near the top of the <script>
   tag that starts with:

       const CONFIG = {

   Everything in there is safe to change.

4. To send it to her: zip the folder (index.html + the 3 videos) and
   send the zip, or upload the folder to a free host (Netlify, Vercel,
   or Google Drive with "anyone with the link") and send her the link.
